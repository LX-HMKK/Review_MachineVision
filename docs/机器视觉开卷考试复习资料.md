## 二、题型作答模板

### 1. 选择题 / 判断题

#### 通用作答骨架

1. 先判题干在问 `定义 / 性质 / 步骤 / 场景` 中的哪一类，再对应回忆本课术语。
2. 选择题先排除明显错项；判断题先看是否出现 `一定`、`总是`、`唯一`、`所有` 这类绝对化表述。
3. 定义题只答“它是什么”；比较题只答“核心区别”；步骤题重点看顺序；场景题重点看噪声类型、输出目标、是否要定位。

#### 最短句式模板

1. 定义题：`X 是……，其核心特征是……。`
2. 比较题：`A 与 B 的主要区别在于……；A 更强调……，B 更强调……。`
3. 判断题：`该说法错误/正确，因为……。`
4. 场景题：`若题目条件是……，更适合用……，因为……。`

#### 本课高频对象/调用规则

1. 易混概念优先成对调用：`高斯 vs 中值`、`Harris vs Moravec`、`生成式 vs 判别式`、`分类 vs 检测 vs 分割`。
2. 定义题优先回 `关键概念`；若选项涉及公式、判据或不变性，再补看对应章节的 `关键公式与符号意义`。
3. 若选项在考步骤先后，直接调用前文 `必会流程速查`，不要在这里临场展开新流程。

### 2. 计算题

#### 通用作答骨架

1. 先写已知：输入尺寸 `H×W`（或 `W×H`）、核尺寸 `k`、padding `p`、stride `s`、通道数 `C`、卷积核个数 `N`。
2. 再写输出尺寸：
   `W_out = floor((W - k + 2p) / s) + 1`
   `H_out = floor((H - k + 2p) / s) + 1`
   先判 `valid / same / full`，再代数。
3. 再写单点运算量、总运算量、可分离或积分图等优化项，最后做尺寸和量纲自检。

#### 最短句式模板

1. `已知输入为……，卷积核为……，padding 为……，stride 为……。`
2. `因此输出尺寸为……。`
3. `每个输出点需要……次乘加，所以总运算量为……。`
4. `若利用……优化，则复杂度可由……降为……。`

#### 本课高频对象/调用规则

1. 卷积题优先调用 Ch03 的输出尺寸公式、`valid/same/full` 区分和可分离核结论。
2. 若题干出现高斯核，正文最后补一句 `高斯核可分离`；若出现积分图，补一句 `矩形区域求和可常数时间完成`。
3. 公式、符号、复杂度写法不确定时，回看对应章节的 `关键公式与符号意义`，按原符号抄写，不自行换字母。

### 3. 流程题

#### 通用作答骨架

1. 本题只回答 `怎么做，按什么顺序`，不展开和别的方法谁更好。
2. 固定写法：`输入 -> 核心步骤 -> 每步作用 -> 输出`，每步只写一句 `做什么 + 为什么做`。
3. 高频对象参见前文流程速查表，正文展开时按该骨架写，不必在这里重复抄整套细节。

#### 最短句式模板

1. `输入为……。`
2. `首先……，作用是……。`
3. `然后……，作用是……。`
4. `最后……，得到……。`

#### 本课高频对象/调用规则

1. 默认优先调用：`Canny`、`SIFT`、`Bag-of-Features`、`Viola-Jones`。
2. 写流程时先对照前文 `必会流程速查` 的顺序，再把每步作用补成一句话。
3. 若题干只问某一步作用，就截取该步及前后衔接，不要把整条流程全抄上去。

### 4. 论述题

#### 通用作答骨架

1. 本题回答 `为什么这样做，与别的方法相比如何`，不是只默写步骤。
2. 固定骨架：`方法目标 -> 核心思想 -> 关键公式/判据 -> 优缺点 -> 与相近方法比较 -> 适用场景`。
3. 开头先钉住问题对象，结尾一定落到“适合什么，不适合什么”。

#### 最短句式模板

1. `该方法的目标是……。`
2. `它这样做的原因是……，核心思想是……。`
3. `关键公式/判据是……，其中……表示……。`
4. `与……相比，它的优点是……，缺点是……。`
5. `因此它更适用于……，不太适用于……。`

#### 本课高频对象/调用规则

1. 高频论述对象优先调用：`生成式 vs 判别式`、`高斯 vs 中值`、`Harris vs Moravec`、`LBP / BoF`、`分类 vs 检测 vs 分割`。
2. 若论述题涉及公式，至少点一个章节中的核心公式或符号意义；若涉及方法比较，优先从目标、信息利用方式、鲁棒性、代价四个角度对比。
3. 展开正文时，先回该章节 `关键概念` 与 `关键公式与符号意义`，再把 `可能出题方式` 中对应题型的要点改写成完整答案。

#### 与章节正文的映射规则

1. `关键概念` 主要对应选择/判断题，用来答定义、性质、辨析。
2. `关键公式与符号意义` 主要对应计算题、论述题，用来答代数步骤、判据来源、符号解释。
3. `可能出题方式` 使用时按四类题型分开看：
   选择/判断题：优先抽定义、性质、易混概念。
   计算题：优先抽公式代入、复杂度、符号说明。
   流程题：优先抽步骤顺序、每步作用、输入输出。
   论述题：优先抽方法目标、核心思想、优缺点、对比对象。

## 三、分章节完整复习资料

### Ch02 成像与标定
#### 本章核心考点
- 针孔成像模型要能说清三层关系：世界坐标中的点先经外参变到相机坐标，再经透视投影落到像平面，最后经内参换成像素坐标。考试常把 `内参 / 外参 / 投影矩阵 / 齐次坐标` 放在同一题里混合考。
- 透视投影的本质是“按深度缩放”。同一物体离相机越远，成像越小；这正是 `近大远小` 的来源。若题目问为什么投影不是普通线性变换，要答：因为最终要除以深度 `z`。
- 标定题的重点不只是“求参数”，还包括“为什么能求、什么时候会退化”。核心要点是：需要足够多的 3D-2D 对应约束，且点集几何分布不能让模型退化。

#### 关键概念
- `针孔成像`：理想相机模型，所有光线都通过同一个光心。优点是几何关系清楚，便于推导；缺点是忽略了真实镜头畸变和模糊。
- `齐次坐标`：把二维点写成 `p = (u, v, 1)^T`、三维点写成 `P = (X, Y, Z, 1)^T`，这样透视投影可先写成矩阵乘法，再在最后一步做归一化。要点是“齐次坐标本身不是最终像素坐标，而是便于表示投影的中间形式”。
- `内参`：描述相机自身成像几何，通常包括焦距在像素坐标中的尺度、主点位置、像素轴偏斜等。它回答“相机坐标中的点如何映到图像像素坐标”。
- `外参`：描述世界坐标系相对于相机坐标系的位置和姿态，通常由旋转矩阵 `R` 与平移向量 `t` 构成。它回答“世界点先怎样变到相机坐标系”。
- `投影矩阵`：把外参与内参合并后的整体映射，形式上是一个 `3×4` 矩阵。它压缩了“刚体变换 + 透视投影 + 像素变换”三个步骤。
- `标定目标`：通过已知几何结构的标定物，例如棋盘格，建立已知 3D 点与图像 2D 点之间的对应关系，从而估计相机参数。张正友标定法是课程里最常见的平面标定案例。
- `退化条件`：若标定点分布太差，或约束不足，参数将不可唯一确定或数值极不稳定。常见表达是“所有点共线一定退化；在一般三维标定框架下，所有点共面会使部分参数估计困难或不稳定，需要额外结构假设”。

#### 关键公式与符号意义
- 透视投影基本式：`x' = f x / z, y' = f y / z`。这里 `f` 是焦距，`(x, y, z)` 是相机坐标系中的三维点，`(x', y')` 是像平面坐标。核心含义：成像坐标与深度 `z` 成反比，所以越远越小。常见误区是把它误写成 `x' = fx`，漏掉除以 `z`。
- 相机总体投影模型：`\mathbf{p} \sim K [R|t] \mathbf{P}_w`。其中 `\mathbf{P}_w` 是世界坐标中的齐次点，`[R|t]` 是外参，`K` 是内参矩阵，`\mathbf{p}` 是图像点的齐次坐标。`∼` 表示“相差一个非零尺度因子”，不能当成普通相等号直接逐项比较。
- 常见内参矩阵写法：`K = [[f_x, s, c_x], [0, f_y, c_y], [0, 0, 1]]`。`f_x, f_y` 是 x/y 方向的像素尺度焦距，`(c_x, c_y)` 是主点，`s` 是像素轴偏斜。若题目默认像素轴正交，常取 `s = 0`。
- 外参变换：`\mathbf{P}_c = R \mathbf{P}_w + t`。`\mathbf{P}_c` 是相机坐标中的点。`R` 表示旋转，`t` 表示平移。常见考法是问“外参描述的是谁相对谁”，标准说法是“世界坐标系到相机坐标系的刚体变换”。
- 畸变参数常以径向畸变系数 `k_1, k_2, k_3` 表示。考试更常考概念而不是完整公式，答题时要说明：径向畸变会让远离主点的区域偏离理想针孔投影，表现为桶形或枕形。
- `标准投影作答链`：`世界点 -> 相机坐标 -> 归一化像平面 -> 像素坐标`。考试写投影题时按这四步顺序抄：先用外参变到相机坐标，再除以深度得到归一化像平面坐标，最后乘内参得到像素坐标。

#### 高频比较与易错点
- `内参 vs 外参`：内参是相机自身成像属性，不随相机在场景中移动而变化；外参是相机相对场景的位姿，一换位置或朝向就变。易错点是把焦距写成外参、把平移写成内参。
- `齐次坐标表示 vs 欧式坐标表示`：齐次坐标是为了把投影写成矩阵形式，不代表多了一个真实空间维度。最后必须除以最后一维恢复到普通坐标。
- `投影矩阵 vs 内参矩阵`：投影矩阵是 `3×4`，同时含外参与内参；内参矩阵是 `3×3`，只负责相机坐标到像素坐标。考试若问“哪个矩阵编码了相机位置和方向”，答案一定是外参或整体投影矩阵，不是单独的 `K`。
- `平面标定可行` 与 `一般三维退化` 不矛盾：张正友法利用多视角平面棋盘格，通过单应关系增加约束，所以“平面标定板可以标定”是对的；但若在更一般的线性恢复语境下只给退化几何分布，某些参数可能不稳定。答题时要看题目语境。

#### 可能出题方式
- `选择`：判断哪个参数属于内参，哪个属于外参；判断外参的物理意义是不是“相机的位置和方向”；判断针孔模型是否包含畸变。
- `判断`：例如“透视投影是线性变换”一般应判错，因为要除以 `z`；“齐次坐标只是便于表示投影”一般判对。
- `计算`：给出 `K`、`R`、`t` 或简化的 `f` 与三维点坐标，要求写出投影过程、求像点坐标，或说明自由度。写题时先写坐标变换，再写投影，再写像素化。
- `流程`：简述相机标定流程时可写“准备标定物 -> 拍摄多视角图像 -> 提取角点 -> 建立 3D-2D 对应 -> 求解内外参与畸变 -> 重投影误差优化”。
- `论述`：为什么会出现退化条件、为什么标定点分布不能太单一、为什么平面棋盘格也能完成标定。这类题不要只背定义，要指出“约束不足或相关性过强会导致参数不可稳定分离”。
- `考试句式`：`重投影误差就是把估计参数下的三维点重新投到图像上，再和真实检测像点比较，误差越小说明标定结果越符合观测。`
- `考试句式`：`平面棋盘格为什么在多视角下可解：因为同一平面在不同视角下提供多组单应约束，可把内参与各次拍摄位姿逐步分离出来。`

### Ch03 滤波
#### 本章核心考点
- Ch03 是高频大题章，必须会 `卷积定义`、`full / same / valid`、`边界处理`、`可分离性和复杂度`，以及 `高斯 vs 盒式 vs 中值` 的适用场景。
- 计算题通常围绕“输出尺寸、乘加次数、可分离核降复杂度”展开；论述题常考为什么高斯更自然、为什么中值适合椒盐噪声、为什么 `unsharp masking` 属于锐化。
- 这章不能只会背名字，必须能写出“是什么、为什么、代价是什么”。例如高斯平滑降低高频噪声，但会损失细节；中值抑制离群点强，但它不是线性卷积。

#### 关键概念
- `卷积`：用一个核在图像上滑动，对当前邻域做加权求和。严格定义中核会翻转；若不翻转更接近相关。考试若题目只给模板计算，通常默认按课程约定直接套卷积/滤波框架作答。
- `full / same / valid`：三者本质是输出保留范围不同。`full` 保留所有发生重叠的位置，输出最大；`same` 输出尺寸与原图一致；`valid` 只保留核完全落在图像内部的位置，输出最小。
- `边界处理`：核滑到边缘时，需要决定外部像素如何补。常见策略有零填充、复制边界、镜像、循环。边界处理会明显影响边缘区域结果，但不改变卷积核本身。
- `盒式滤波`：邻域内所有权重相等的平均滤波。实现简单，但容易产生块状感，边缘过渡不够自然。
- `高斯滤波`：按距离衰减加权，离中心近的像素权重大，属于线性低通滤波。它对高斯噪声更合适，也比盒式滤波更平滑自然。
- `中值滤波`：取邻域排序后的中位数作为输出，是非线性滤波。它对椒盐噪声、脉冲噪声更稳，因为异常值不会像均值那样把结果带偏。
- `可分离性`：若二维核可写成两个一维核的外积，就能先按行卷积、再按列卷积。高斯核是最典型的可分离核。
- `unsharp masking`：先把图像模糊得到低频部分，再用原图减去模糊图得到细节，把细节按一定权重加回原图，从而实现锐化。

#### 关键公式与符号意义
- 二维卷积定义：`(f * g)[m, n] = Σ_k Σ_l f[m-k, n-l] g[k, l]`。`f` 是图像，`g` 是卷积核，`m,n` 是输出位置，`k,l` 是核内索引。核心含义是“输出像素由邻域加权和决定”。常见误区是只会写式子，不说明每个求和项代表邻域匹配。
- 输出尺寸公式：`W_out = floor((W - k + 2p) / s) + 1`，`H_out = floor((H - k + 2p) / s) + 1`。`W,H` 是输入尺寸，`k` 是核宽，`p` 是 padding，`s` 是 stride。常见考法是先让你判别 `full / same / valid`，再写具体尺寸；不要跳过这一层直接乱代。
- 高斯核：`G(x,y)=1/(2πσ^2) * exp(-(x^2+y^2)/(2σ^2))`。`σ` 控制平滑尺度，越大说明权重分布越宽、模糊越强。常见误区是把 `σ` 变大理解成“边缘更清楚”，实际上相反。
- 可分离性：`G(x,y)=G_x(x) G_y(y)`。其核心不是形式漂亮，而是复杂度从二维卷积的 `O(HWk^2)` 降到两次一维卷积的 `O(HWk)`。若题目问“加速原因”，要答“减少了每个输出点的乘加次数”，不要只说“因为可以分开算”。
- `unsharp masking`：`f_sharp = f + α(f - f_blur) = (1+α)f - αf_blur`。`f` 是原图，`f_blur` 是平滑结果，`α` 是细节增强系数。核心含义是“把高频细节加回去”；常见误区是把它误当成去噪方法，实际上它会放大边缘，也可能放大噪声。

#### 高频比较与易错点
- `高斯 vs 盒式 vs 中值`：盒式是等权平均，简单但容易产生不自然模糊；高斯是距离加权平均，适合高斯噪声，效果更自然；中值是非线性排序操作，最适合椒盐噪声。题目若问“谁最好”，一定要结合噪声类型答，不能脱离场景。
- `线性 vs 非线性`：盒式和高斯属于线性滤波，可写成卷积；中值滤波不满足线性叠加，不是卷积。判断题非常喜欢考这一点。
- `same` 不等于“没有边界问题”`：same` 只是输出尺寸不变，通常仍需 padding；若 padding 策略不同，边缘像素值也会不同。
- `可分离性和复杂度`：可分离核降低的是计算量，不改变数学结果。易错点是把复杂度从 `O(HWk^2)` 错写成 `O(HW + k)`，或者忘记两次一维卷积仍然各要扫整幅图。
- `锐化 vs 去噪`：平滑通过抑制高频达到去噪，锐化则强调高频细节。`unsharp masking` 的思路是“原图减模糊图得到细节”，不是“模糊后更清楚”。
- `考场速判规则`：`full` 输出最大、保留所有重叠；`same` 输出尺寸尽量与输入一致；`valid` 只保留核完全落入原图的位置，因此边界保留最少、输出最小。
- `考场速判规则`：`padding` 增大时输出尺寸会变大或至少更容易保持不变；在 `same` 中通常正是靠 padding 才把尺寸维持回输入大小。
- `考场速判规则`：`unsharp masking` 能增强细节的前提是信噪比不能太差；若信噪比很低，被加回去的不只是细节，噪声也会一起被放大。

#### 可能出题方式
- `选择`：判断 `full / same / valid` 哪个输出最大；判断中值滤波是否线性；判断哪种滤波更适合椒盐噪声或高斯噪声。
- `判断`：例如“高斯核可分离”应判对；“中值滤波可写成线性卷积”应判错；“same 卷积不需要边界处理”通常判错。
- `计算`：给输入尺寸、核大小、padding、stride，要求算输出尺寸；给一个 `3×3` 或 `5×5` 核，要求算单点卷积或总乘加次数；给可分离核，要求比较直接卷积与分离卷积复杂度。
- `流程`：说明 `unsharp masking` 时，按“先平滑 -> 得到细节 `f-f_blur` -> 按系数加回 -> 得到锐化图像”作答即可。
- `论述`：高斯、盒式、中值的比较题要围绕“权重机制、是否线性、适用噪声、保边能力、计算代价”展开；复杂度题要显式写出 `可分离性和复杂度` 的关系。

### Ch04 边缘检测
#### 本章核心考点
- Ch04 的主线是“导数找变化，平滑抗噪声，Canny 把边缘做细并连起来”。考试既考算子辨析，也考完整流程，尤其偏爱 `双阈值` 与 `滞后连接`。
- 必须会说明为什么“先平滑后求导”。原因不是形式上的固定顺序，而是求导会放大高频噪声，若不先平滑，边缘图会被噪声污染。
- 必须掌握 Canny 五步：高斯平滑、求梯度、非极大值抑制、双阈值、滞后连接。题目要求写步骤时，顺序不能错。

#### 关键概念
- `梯度 / 导数`：图像灰度函数在空间上的变化率。灰度变化快的位置往往对应边缘，因此一阶导数是边缘检测的核心工具。
- `离散差分核`：用有限差分近似连续导数。`[-1,1]` 是最简单的一维差分；Roberts、Prewitt、Sobel 都是其二维扩展。它们的差别主要体现在模板尺寸、方向与抗噪能力。
- `先平滑后求导`：真实图像含噪，导数会把噪声也放大。先做高斯平滑，再计算导数，可得到更稳定的边缘响应。
- `高斯导数 / DoG`：本章主线仍是高斯导数与 Canny；DoG 这里只作补充了解，可知道它和尺度空间有关，但考试重点不是靠 DoG 展开作答。
- `NMS`：非极大值抑制。沿梯度方向比较局部邻居，只保留幅值局部最大的点，把宽边变细边。
- `双阈值`：用高阈值和低阈值把像素分成强边缘、弱边缘、非边缘。这样做是为了同时降低漏检和误检。
- `滞后连接`：只保留与强边缘连通的弱边缘，丢掉孤立弱响应。它利用“真实边缘通常是连续的”这一假设。

#### 关键公式与符号意义
- 梯度向量：`\nabla I = [I_x, I_y]^T`。`I_x`、`I_y` 分别是 x、y 方向的一阶导数。核心含义：梯度指向灰度增长最快的方向，而边缘方向与梯度方向垂直。常见误区是把“梯度方向”和“边缘延伸方向”当成同一个方向。
- 梯度幅值与方向：`|\nabla I| = sqrt(I_x^2 + I_y^2)`，`θ = atan2(I_y, I_x)`。`|\nabla I|` 用来判断边缘强弱，`θ` 用于 NMS 判断该沿哪个方向比较。考试若问 NMS 为什么需要方向信息，就应回到这两个量。
- 高斯导数思想：`∂(G * I)/∂x = (∂G/∂x) * I`。这说明“先高斯平滑再求导”与“直接用高斯导数核卷积”是等价的。核心考法是解释为什么能把两步合成一步。
- Canny 双阈值分类：当 `|\nabla I| ≥ T_H` 时为强边缘；`T_L ≤ |\nabla I| < T_H` 时为弱边缘；`|\nabla I| < T_L` 时抑制。`T_H`、`T_L` 分别是高低阈值。常见误区是把弱边缘直接保留；正确做法是交给滞后连接再决定。

#### 高频比较与易错点
- `Roberts / Prewitt / Sobel`：Roberts 是 `2×2`、定位敏感但更怕噪声；Prewitt 是 `3×3`、结构简单；Sobel 也是 `3×3`，但中央权重更大，兼顾差分与平滑，抗噪性更好。选择题很爱考这一组。
- `先求导后平滑` 是错的默认直觉：顺序一错，噪声会先被放大，再难以补救。课程强调的是“先抑噪，再检测变化”。
- `NMS vs 双阈值`：NMS 的任务是“细化边缘”，双阈值的任务是“分级筛选边缘”，二者不互相替代。很多同学会把双阈值误写在 NMS 前面。
- `双阈值 vs 滞后连接`：双阈值只做分类，不决定最终保留哪些弱边缘；滞后连接才根据连通关系决定弱边缘是否留下。判断题喜欢把这两步混成一步。
- `DoG`：补充了解即可，它强调尺度差分思想；本章真正要稳拿分的主线仍是高斯导数、梯度/NMS 和 Canny 五步。

#### 可能出题方式
- `选择`：判断某差分模板检测的边缘方向；比较 Sobel 和 Roberts 的模板大小与抗噪能力；判断 Canny 步骤中哪一步不属于标准流程。
- `判断`：例如“梯度方向与边缘方向相同”应判错；“Canny 中 NMS 用于细化边缘”应判对；“双阈值后所有弱边缘都保留”应判错。
- `计算`：给 `I_x`、`I_y`，算梯度幅值和方向；给差分模板与小图像，求某点响应；若题目较基础，也可能只要求说明哪类算子更容易受噪声影响。
- `流程`：完整写 Canny 五步时建议固定模板：`高斯平滑 -> 计算梯度幅值与方向 -> NMS -> 双阈值 -> 滞后连接`，并在每步后补一句作用。
- `论述`：重点会落在“为什么先平滑后求导”“NMS 如何把边缘变细”“双阈值与滞后连接如何兼顾检出率与误检率”。回答时一定显式写出 `双阈值` 和 `滞后连接`。

### Ch05_1 拟合
#### 本章核心考点
- 本章去年分值低，但属于方法基础章，重点覆盖 `最小二乘`、`全最小二乘`、`鲁棒估计`、`RANSAC`。深度可以略低于 Ch03/Ch04，但术语不能混。
- 核心问题是：已知模型类型时，怎样从一堆带噪点里估计参数；如果存在离群点，普通最小二乘为什么会失效；RANSAC 为什么更稳。
- 题目若与 Ch05_2 联动，常把“拟合一条线”作为例子，借此区分参数估计法与投票法。

#### 关键概念
- `最小二乘`：选择参数，使残差平方和最小。在线拟合里，常见形式是让点到模型的误差尽可能小。它适合噪声较小、离群点较少的情况。
- `垂直最小二乘`：以 `y = mx + b` 为模型，最小化各点在 y 方向上的偏差平方和。优点是推导简单；缺点是不具旋转不变性，遇到近垂直直线会很不稳定。
- `全最小二乘`：最小化点到拟合直线的正交距离，而不是只看某一个坐标方向的误差。它比普通直线回归更符合几何意义，也更适合方向任意的直线。
- `鲁棒估计`：通过让大残差点的影响饱和或降低权重，减轻离群点对结果的破坏。思想上比普通最小二乘更抗异常值。
- `RANSAC`：随机抽最小样本集，生成候选模型，再统计支持该模型的内点数，重复多次选出最好模型。它适合内点中混有较多离群点的场景。

#### 关键公式与符号意义
- 普通最小二乘直线拟合：`E = Σ_i (y_i - m x_i - b)^2`。`(x_i, y_i)` 是样本点，`m` 是斜率，`b` 是截距。核心含义：让纵向残差平方和最小。常见考法是问“为什么叫平方和”，答“因为误差平方后可避免正负抵消并惩罚大误差”。
- 正规方程写法：`X^T X β = X^T Y`。`β` 是待估参数向量。考试通常不要求你完整矩阵推导，但要知道它是最小二乘闭式解的基础。
- 全最小二乘直线形式：`ax + by = d`，且常加约束 `a^2 + b^2 = 1`。这里 `(a,b)` 是单位法向量，`d` 是直线到原点的有符号距离。核心含义：用法向形式避免垂直线斜率无穷大的问题。
- 点到直线距离：`|a x_i + b y_i - d|`，在 `a^2+b^2=1` 时就是正交距离。全最小二乘最小化的是这些距离的平方和。常见误区是忘了单位法向量约束，导致距离表达式不成立。
- RANSAC 迭代次数常用关系：`N = log(1-p) / log(1-(1-e)^s)`。`p` 是期望成功概率，`e` 是离群点比例，`s` 是最小样本数。考试更常考符号意义和趋势：离群点越多、最小样本数越大，需要的迭代次数越多。

#### 高频比较与易错点
- `最小二乘 vs 全最小二乘`：前者通常最小化某一坐标方向残差，推导简单；后者最小化正交距离，几何意义更合理。易错点是把两者都说成“点到直线距离最小”。
- `最小二乘 vs 鲁棒估计`：最小二乘对大残差平方惩罚，因此极易被离群点带偏；鲁棒估计会压低大残差点权重，更稳但求解常需迭代。
- `鲁棒估计 vs RANSAC`：鲁棒估计通常是在全部样本上做加权优化；`RANSAC` 是随机采样加一致性筛选。若离群点比例很高，RANSAC 往往更合适。
- `RANSAC` 不是“永远最优”：它依赖阈值、迭代次数、最小样本数等参数，内点比例太低时会很慢甚至失败。论述题里要写出这一代价。
- `RANSAC 内点阈值`：阈值过小会把本应属于模型的点误判成外点，导致内点数不足、模型不稳定；阈值过大会把离群点也吞进去，导致估计结果被污染。

#### 可能出题方式
- `选择`：判断哪种方法对离群点更鲁棒；判断普通最小二乘是否适合垂直直线；判断 `RANSAC` 的基本步骤。
- `判断`：例如“RANSAC 直接使用全部点一次求闭式解”应判错；“全最小二乘最小化的是正交距离”应判对。
- `计算`：若考得浅，通常是写残差函数、说明参数含义，或根据离群点比例判断迭代次数变化趋势，不一定要求完整矩阵求解。
- `流程`：写 `RANSAC` 时建议固定为“随机采样最小子集 -> 拟合候选模型 -> 计算内点集合 -> 记录最佳模型 -> 用全部内点重估参数”。
- `论述`：可围绕“为什么最小二乘怕离群点”“为什么全最小二乘比竖直残差更自然”“RANSAC 何时优于普通拟合”作答，显式写出 `RANSAC` 的适用场景与代价。

### Ch05_2 霍夫变换
#### 本章核心考点
- 霍夫变换的核心不是“会背公式”而是理解映射关系：`图像空间中的点 -> 参数空间中的曲线`，多个共线点在参数空间中交于同一峰值。
- 直线检测必须会写 `ρ = x cosθ + y sinθ`，并说明 `ρ`、`θ` 的几何意义，以及为什么这种表示优于 `y = mx + b`。
- 还要会说明 `累加器投票`、`噪声影响`、`圆霍夫`、`广义霍夫`，并能与 `RANSAC` 做简要对比。

#### 关键概念
- `参数空间`：不是在原图上找线，而是把“模型参数”当成坐标轴去统计支持度。图像中的几何结构会在参数空间里形成峰值。
- `图像空间中的点 -> 参数空间中的曲线`：对一条未知直线上的单个点来说，可能通过它的直线不止一条，所以在参数空间里它不会对应单一点，而是一条候选曲线。
- `累加器投票`：把参数空间离散成网格，每个边缘点把自己支持的参数格子加一票。得票高的格子代表很多点共同支持该模型。
- `ρ-θ 表示`：用法向距离和法向角度描述直线，避免斜率无穷大的问题，因此可以统一表示竖直线。
- `圆霍夫`：将模型从直线扩展到圆，参数通常是圆心和半径。参数维数更高，所以计算量显著上升。
- `广义霍夫`：不仅可找直线和圆，也可找由模板定义的更复杂形状。核心思想仍然是“模板特征投票到参考点或参数配置”。

#### 关键公式与符号意义
- 直线极坐标表示：`ρ = x cosθ + y sinθ`。`ρ` 是原点到直线的有符号垂直距离，`θ` 是该垂线与 x 轴的夹角，也可理解为直线法向量方向。核心含义：一条直线由 `(ρ, θ)` 唯一确定。常见误区是把 `θ` 当成直线本身的倾角；更准确地说，它是法向角。
- 点到参数空间映射：对固定图像点 `(x_0, y_0)`，满足该点的所有直线参数组成曲线 `ρ(θ) = x_0 cosθ + y_0 sinθ`。因此一个点在参数空间中是一条正弦型曲线，而不是一个点。
- 累加器更新：对每个边缘点遍历离散 `θ`，计算对应 `ρ`，令 `H(θ, ρ) = H(θ, ρ) + 1`。`H` 是累加器数组。常见考法是问“峰值代表什么”，应答“代表很多边缘点对同一参数组合达成一致投票”。
- 圆霍夫常见参数式：`(x-a)^2 + (y-b)^2 = r^2`。`(a,b)` 是圆心，`r` 是半径。若 `r` 已知，则参数空间通常是二维 `(a,b)`；若 `r` 也未知，则是三维 `(a,b,r)`。这正是其计算代价高于直线霍夫的原因。

#### 高频比较与易错点
- `m-b 表示 vs ρ-θ 表示`：`y = mx + b` 对垂直线不友好，且参数域无界；`ρ-θ` 统一且稳定。若题目问为什么课程更推崇 `ρ-θ`，答这一点即可。
- `图像空间的直线` 与 `参数空间的曲线` 不要写反：一条图像中的直线对应参数空间中的一个点；一个图像中的点对应参数空间中的一条曲线。这个方向关系是本章最容易丢分的地方。
- `噪声影响`：噪声点会产生零散投票，真实结构会形成集中峰值；但噪声过多、参数网格过细或过粗，都会让峰值模糊或产生假峰。答题时要写“离散化粒度”这一层。
- `霍夫 vs RANSAC`：二者都能在噪声和离群点下找模型。霍夫更偏全局投票，可同时找多条线，但参数维数升高时代价大；`RANSAC` 更偏随机采样与验证，适合单模型或少量模型拟合。不要简单说谁绝对更好。
- `圆霍夫 vs 广义霍夫`：圆霍夫仍然是固定参数化形状；广义霍夫是把复杂模板特征也变成投票表，适用范围更广，但建模与计算更复杂。
- `离散化粒度标准答法`：参数空间离散过粗会把不同直线压到同一格里，定位变粗、峰值混叠；离散过细会让投票分散、峰值不明显，同时计算量和存储量上升。

#### 可能出题方式
- `选择`：判断图像空间中的点在霍夫空间里对应什么；判断 `ρ = x cosθ + y sinθ` 中 `θ` 的意义；判断圆霍夫的参数维度。
- `判断`：例如“图像中的一条直线对应参数空间中的一条曲线”应判错；“霍夫变换可以检测多条直线”应判对；“RANSAC 与霍夫都能处理一定程度的噪声”通常判对。
- `计算`：给定一个点 `(x,y)` 和若干 `θ`，要求计算对应 `ρ`；或者给出参数峰值 `(ρ, θ)`，让你写出对应直线方程。此时务必先解释 `ρ`、`θ` 的含义。
- `流程`：写标准直线霍夫时可答“边缘提取 -> 离散参数空间 -> 每个边缘点按 `ρ = x cosθ + y sinθ` 投票 -> 在累加器中找峰值 -> 将峰值反映回图像空间得到直线”。
- `论述`：可考“霍夫为什么对断裂边缘仍有一定鲁棒性”“噪声为什么会造成假峰”“霍夫与 RANSAC 的适用场景比较”。这类题要同时写投票思想和代价。
