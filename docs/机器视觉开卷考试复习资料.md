## 二、题型作答模板

### 1. 选择题 / 判断题

#### 通用作答骨架

1. 先判题干在问 `定义 / 性质 / 步骤 / 场景` 中的哪一类，再对应回忆本课术语。
2. 选择题先排除明显错项；判断题先看是否出现 `一定`、`总是`、`唯一`、`所有` 这类绝对化表述。
3. 定义题只答“它是什么”；比较题只答“核心区别”；步骤题重点看顺序；场景题重点看噪声类型、输出目标、是否要定位。

#### 最短句式模板

1. 定义题：`X 是……，其核心特征是……。`
2. 比较题：`A 与 B 的主要区别在于……；A 更强调……，B 更强调……。`
3. 判断题：`该说法错误/正确，因为……。`
4. 场景题：`若题目条件是……，更适合用……，因为……。`

#### 本课高频对象/调用规则

1. 易混概念优先成对调用：`高斯 vs 中值`、`Harris vs Moravec`、`生成式 vs 判别式`、`分类 vs 检测 vs 分割`。
2. 定义题优先回 `关键概念`；若选项涉及公式、判据或不变性，再补看对应章节的 `关键公式与符号意义`。
3. 若选项在考步骤先后，直接调用前文 `必会流程速查`，不要在这里临场展开新流程。

### 2. 计算题

#### 通用作答骨架

1. 先写已知：输入尺寸 `H×W`（或 `W×H`）、核尺寸 `k`、padding `p`、stride `s`、通道数 `C`、卷积核个数 `N`。
2. 再写输出尺寸：
   `W_out = floor((W - k + 2p) / s) + 1`
   `H_out = floor((H - k + 2p) / s) + 1`
   先判 `valid / same / full`，再代数。
3. 再写单点运算量、总运算量、可分离或积分图等优化项，最后做尺寸和量纲自检。

#### 最短句式模板

1. `已知输入为……，卷积核为……，padding 为……，stride 为……。`
2. `因此输出尺寸为……。`
3. `每个输出点需要……次乘加，所以总运算量为……。`
4. `若利用……优化，则复杂度可由……降为……。`

#### 本课高频对象/调用规则

1. 卷积题优先调用 Ch03 的输出尺寸公式、`valid/same/full` 区分和可分离核结论。
2. 若题干出现高斯核，正文最后补一句 `高斯核可分离`；若出现积分图，补一句 `矩形区域求和可常数时间完成`。
3. 公式、符号、复杂度写法不确定时，回看对应章节的 `关键公式与符号意义`，按原符号抄写，不自行换字母。

### 3. 流程题

#### 通用作答骨架

1. 本题只回答 `怎么做，按什么顺序`，不展开和别的方法谁更好。
2. 固定写法：`输入 -> 核心步骤 -> 每步作用 -> 输出`，每步只写一句 `做什么 + 为什么做`。
3. 高频对象参见前文流程速查表，正文展开时按该骨架写，不必在这里重复抄整套细节。

#### 最短句式模板

1. `输入为……。`
2. `首先……，作用是……。`
3. `然后……，作用是……。`
4. `最后……，得到……。`

#### 本课高频对象/调用规则

1. 默认优先调用：`Canny`、`SIFT`、`Bag-of-Features`、`Viola-Jones`。
2. 写流程时先对照前文 `必会流程速查` 的顺序，再把每步作用补成一句话。
3. 若题干只问某一步作用，就截取该步及前后衔接，不要把整条流程全抄上去。

### 4. 论述题

#### 通用作答骨架

1. 本题回答 `为什么这样做，与别的方法相比如何`，不是只默写步骤。
2. 固定骨架：`方法目标 -> 核心思想 -> 关键公式/判据 -> 优缺点 -> 与相近方法比较 -> 适用场景`。
3. 开头先钉住问题对象，结尾一定落到“适合什么，不适合什么”。

#### 最短句式模板

1. `该方法的目标是……。`
2. `它这样做的原因是……，核心思想是……。`
3. `关键公式/判据是……，其中……表示……。`
4. `与……相比，它的优点是……，缺点是……。`
5. `因此它更适用于……，不太适用于……。`

#### 本课高频对象/调用规则

1. 高频论述对象优先调用：`生成式 vs 判别式`、`高斯 vs 中值`、`Harris vs Moravec`、`LBP / BoF`、`分类 vs 检测 vs 分割`。
2. 若论述题涉及公式，至少点一个章节中的核心公式或符号意义；若涉及方法比较，优先从目标、信息利用方式、鲁棒性、代价四个角度对比。
3. 展开正文时，先回该章节 `关键概念` 与 `关键公式与符号意义`，再把 `可能出题方式` 中对应题型的要点改写成完整答案。

#### 与章节正文的映射规则

1. `关键概念` 主要对应选择/判断题，用来答定义、性质、辨析。
2. `关键公式与符号意义` 主要对应计算题、论述题，用来答代数步骤、判据来源、符号解释。
3. `可能出题方式` 使用时按四类题型分开看：
   选择/判断题：优先抽定义、性质、易混概念。
   计算题：优先抽公式代入、复杂度、符号说明。
   流程题：优先抽步骤顺序、每步作用、输入输出。
   论述题：优先抽方法目标、核心思想、优缺点、对比对象。

## 三、分章节完整复习资料

### Ch02 成像与标定
#### 本章核心考点
- 针孔成像模型要能说清三层关系：世界坐标中的点先经外参变到相机坐标，再经透视投影落到像平面，最后经内参换成像素坐标。考试常把 `内参 / 外参 / 投影矩阵 / 齐次坐标` 放在同一题里混合考。
- 透视投影的本质是“按深度缩放”。同一物体离相机越远，成像越小；这正是 `近大远小` 的来源。若题目问为什么投影不是普通线性变换，要答：因为最终要除以深度 `z`。
- 标定题的重点不只是“求参数”，还包括“为什么能求、什么时候会退化”。核心要点是：需要足够多的 3D-2D 对应约束，且点集几何分布不能让模型退化。

#### 关键概念
- `针孔成像`：理想相机模型，所有光线都通过同一个光心。优点是几何关系清楚，便于推导；缺点是忽略了真实镜头畸变和模糊。
- `齐次坐标`：把二维点写成 `p = (u, v, 1)^T`、三维点写成 `P = (X, Y, Z, 1)^T`，这样透视投影可先写成矩阵乘法，再在最后一步做归一化。要点是“齐次坐标本身不是最终像素坐标，而是便于表示投影的中间形式”。
- `内参`：描述相机自身成像几何，通常包括焦距在像素坐标中的尺度、主点位置、像素轴偏斜等。它回答“相机坐标中的点如何映到图像像素坐标”。
- `外参`：描述世界坐标系相对于相机坐标系的位置和姿态，通常由旋转矩阵 `R` 与平移向量 `t` 构成。它回答“世界点先怎样变到相机坐标系”。
- `投影矩阵`：把外参与内参合并后的整体映射，形式上是一个 `3×4` 矩阵。它压缩了“刚体变换 + 透视投影 + 像素变换”三个步骤。
- `标定目标`：通过已知几何结构的标定物，例如棋盘格，建立已知 3D 点与图像 2D 点之间的对应关系，从而估计相机参数。张正友标定法是课程里最常见的平面标定案例。
- `退化条件`：若标定点分布太差，或约束不足，参数将不可唯一确定或数值极不稳定。常见表达是“所有点共线一定退化；在一般三维标定框架下，所有点共面会使部分参数估计困难或不稳定，需要额外结构假设”。

#### 关键公式与符号意义
- 透视投影基本式：`x' = f x / z, y' = f y / z`。这里 `f` 是焦距，`(x, y, z)` 是相机坐标系中的三维点，`(x', y')` 是像平面坐标。核心含义：成像坐标与深度 `z` 成反比，所以越远越小。常见误区是把它误写成 `x' = fx`，漏掉除以 `z`。
- 相机总体投影模型：`\mathbf{p} \sim K [R|t] \mathbf{P}_w`。其中 `\mathbf{P}_w` 是世界坐标中的齐次点，`[R|t]` 是外参，`K` 是内参矩阵，`\mathbf{p}` 是图像点的齐次坐标。`∼` 表示“相差一个非零尺度因子”，不能当成普通相等号直接逐项比较。
- 常见内参矩阵写法：`K = [[f_x, s, c_x], [0, f_y, c_y], [0, 0, 1]]`。`f_x, f_y` 是 x/y 方向的像素尺度焦距，`(c_x, c_y)` 是主点，`s` 是像素轴偏斜。若题目默认像素轴正交，常取 `s = 0`。
- 外参变换：`\mathbf{P}_c = R \mathbf{P}_w + t`。`\mathbf{P}_c` 是相机坐标中的点。`R` 表示旋转，`t` 表示平移。常见考法是问“外参描述的是谁相对谁”，标准说法是“世界坐标系到相机坐标系的刚体变换”。
- 畸变参数常以径向畸变系数 `k_1, k_2, k_3` 表示。考试更常考概念而不是完整公式，答题时要说明：径向畸变会让远离主点的区域偏离理想针孔投影，表现为桶形或枕形。
- `标准投影作答链`：`世界点 -> 相机坐标 -> 归一化像平面 -> 像素坐标`。考试写投影题时按这四步顺序抄：先用外参变到相机坐标，再除以深度得到归一化像平面坐标，最后乘内参得到像素坐标。

#### 高频比较与易错点
- `内参 vs 外参`：内参是相机自身成像属性，不随相机在场景中移动而变化；外参是相机相对场景的位姿，一换位置或朝向就变。易错点是把焦距写成外参、把平移写成内参。
- `齐次坐标表示 vs 欧式坐标表示`：齐次坐标是为了把投影写成矩阵形式，不代表多了一个真实空间维度。最后必须除以最后一维恢复到普通坐标。
- `投影矩阵 vs 内参矩阵`：投影矩阵是 `3×4`，同时含外参与内参；内参矩阵是 `3×3`，只负责相机坐标到像素坐标。考试若问“哪个矩阵编码了相机位置和方向”，答案一定是外参或整体投影矩阵，不是单独的 `K`。
- `平面标定可行` 与 `一般三维退化` 不矛盾：张正友法利用多视角平面棋盘格，通过单应关系增加约束，所以“平面标定板可以标定”是对的；但若在更一般的线性恢复语境下只给退化几何分布，某些参数可能不稳定。答题时要看题目语境。

#### 可能出题方式
- `选择`：判断哪个参数属于内参，哪个属于外参；判断外参的物理意义是不是“相机的位置和方向”；判断针孔模型是否包含畸变。
- `判断`：例如“透视投影是线性变换”一般应判错，因为要除以 `z`；“齐次坐标只是便于表示投影”一般判对。
- `计算`：给出 `K`、`R`、`t` 或简化的 `f` 与三维点坐标，要求写出投影过程、求像点坐标，或说明自由度。写题时先写坐标变换，再写投影，再写像素化。
- `流程`：简述相机标定流程时可写“准备标定物 -> 拍摄多视角图像 -> 提取角点 -> 建立 3D-2D 对应 -> 求解内外参与畸变 -> 重投影误差优化”。
- `论述`：为什么会出现退化条件、为什么标定点分布不能太单一、为什么平面棋盘格也能完成标定。这类题不要只背定义，要指出“约束不足或相关性过强会导致参数不可稳定分离”。
- `考试句式`：`重投影误差就是把估计参数下的三维点重新投到图像上，再和真实检测像点比较，误差越小说明标定结果越符合观测。`
- `考试句式`：`平面棋盘格为什么在多视角下可解：因为同一平面在不同视角下提供多组单应约束，可把内参与各次拍摄位姿逐步分离出来。`

### Ch03 滤波
#### 本章核心考点
- Ch03 是高频大题章，必须会 `卷积定义`、`full / same / valid`、`边界处理`、`可分离性和复杂度`，以及 `高斯 vs 盒式 vs 中值` 的适用场景。
- 计算题通常围绕“输出尺寸、乘加次数、可分离核降复杂度”展开；论述题常考为什么高斯更自然、为什么中值适合椒盐噪声、为什么 `unsharp masking` 属于锐化。
- 这章不能只会背名字，必须能写出“是什么、为什么、代价是什么”。例如高斯平滑降低高频噪声，但会损失细节；中值抑制离群点强，但它不是线性卷积。

#### 关键概念
- `卷积`：用一个核在图像上滑动，对当前邻域做加权求和。严格定义中核会翻转；若不翻转更接近相关。考试若题目只给模板计算，通常默认按课程约定直接套卷积/滤波框架作答。
- `full / same / valid`：三者本质是输出保留范围不同。`full` 保留所有发生重叠的位置，输出最大；`same` 输出尺寸与原图一致；`valid` 只保留核完全落在图像内部的位置，输出最小。
- `边界处理`：核滑到边缘时，需要决定外部像素如何补。常见策略有零填充、复制边界、镜像、循环。边界处理会明显影响边缘区域结果，但不改变卷积核本身。
- `盒式滤波`：邻域内所有权重相等的平均滤波。实现简单，但容易产生块状感，边缘过渡不够自然。
- `高斯滤波`：按距离衰减加权，离中心近的像素权重大，属于线性低通滤波。它对高斯噪声更合适，也比盒式滤波更平滑自然。
- `中值滤波`：取邻域排序后的中位数作为输出，是非线性滤波。它对椒盐噪声、脉冲噪声更稳，因为异常值不会像均值那样把结果带偏。
- `可分离性`：若二维核可写成两个一维核的外积，就能先按行卷积、再按列卷积。高斯核是最典型的可分离核。
- `unsharp masking`：先把图像模糊得到低频部分，再用原图减去模糊图得到细节，把细节按一定权重加回原图，从而实现锐化。

#### 关键公式与符号意义
- 二维卷积定义：`(f * g)[m, n] = Σ_k Σ_l f[m-k, n-l] g[k, l]`。`f` 是图像，`g` 是卷积核，`m,n` 是输出位置，`k,l` 是核内索引。核心含义是“输出像素由邻域加权和决定”。常见误区是只会写式子，不说明每个求和项代表邻域匹配。
- 输出尺寸公式：`W_out = floor((W - k + 2p) / s) + 1`，`H_out = floor((H - k + 2p) / s) + 1`。`W,H` 是输入尺寸，`k` 是核宽，`p` 是 padding，`s` 是 stride。常见考法是先让你判别 `full / same / valid`，再写具体尺寸；不要跳过这一层直接乱代。
- 高斯核：`G(x,y)=1/(2πσ^2) * exp(-(x^2+y^2)/(2σ^2))`。`σ` 控制平滑尺度，越大说明权重分布越宽、模糊越强。常见误区是把 `σ` 变大理解成“边缘更清楚”，实际上相反。
- 可分离性：`G(x,y)=G_x(x) G_y(y)`。其核心不是形式漂亮，而是复杂度从二维卷积的 `O(HWk^2)` 降到两次一维卷积的 `O(HWk)`。若题目问“加速原因”，要答“减少了每个输出点的乘加次数”，不要只说“因为可以分开算”。
- `unsharp masking`：`f_sharp = f + α(f - f_blur) = (1+α)f - αf_blur`。`f` 是原图，`f_blur` 是平滑结果，`α` 是细节增强系数。核心含义是“把高频细节加回去”；常见误区是把它误当成去噪方法，实际上它会放大边缘，也可能放大噪声。

#### 高频比较与易错点
- `高斯 vs 盒式 vs 中值`：盒式是等权平均，简单但容易产生不自然模糊；高斯是距离加权平均，适合高斯噪声，效果更自然；中值是非线性排序操作，最适合椒盐噪声。题目若问“谁最好”，一定要结合噪声类型答，不能脱离场景。
- `线性 vs 非线性`：盒式和高斯属于线性滤波，可写成卷积；中值滤波不满足线性叠加，不是卷积。判断题非常喜欢考这一点。
- `same` 不等于“没有边界问题”`：same` 只是输出尺寸不变，通常仍需 padding；若 padding 策略不同，边缘像素值也会不同。
- `可分离性和复杂度`：可分离核降低的是计算量，不改变数学结果。易错点是把复杂度从 `O(HWk^2)` 错写成 `O(HW + k)`，或者忘记两次一维卷积仍然各要扫整幅图。
- `锐化 vs 去噪`：平滑通过抑制高频达到去噪，锐化则强调高频细节。`unsharp masking` 的思路是“原图减模糊图得到细节”，不是“模糊后更清楚”。
- `考场速判规则`：`full` 输出最大、保留所有重叠；`same` 输出尺寸尽量与输入一致；`valid` 只保留核完全落入原图的位置，因此边界保留最少、输出最小。
- `考场速判规则`：`padding` 增大时输出尺寸会变大或至少更容易保持不变；在 `same` 中通常正是靠 padding 才把尺寸维持回输入大小。
- `考场速判规则`：`unsharp masking` 能增强细节的前提是信噪比不能太差；若信噪比很低，被加回去的不只是细节，噪声也会一起被放大。

#### 可能出题方式
- `选择`：判断 `full / same / valid` 哪个输出最大；判断中值滤波是否线性；判断哪种滤波更适合椒盐噪声或高斯噪声。
- `判断`：例如“高斯核可分离”应判对；“中值滤波可写成线性卷积”应判错；“same 卷积不需要边界处理”通常判错。
- `计算`：给输入尺寸、核大小、padding、stride，要求算输出尺寸；给一个 `3×3` 或 `5×5` 核，要求算单点卷积或总乘加次数；给可分离核，要求比较直接卷积与分离卷积复杂度。
- `流程`：说明 `unsharp masking` 时，按“先平滑 -> 得到细节 `f-f_blur` -> 按系数加回 -> 得到锐化图像”作答即可。
- `论述`：高斯、盒式、中值的比较题要围绕“权重机制、是否线性、适用噪声、保边能力、计算代价”展开；复杂度题要显式写出 `可分离性和复杂度` 的关系。

### Ch04 边缘检测
#### 本章核心考点
- Ch04 的主线是“导数找变化，平滑抗噪声，Canny 把边缘做细并连起来”。考试既考算子辨析，也考完整流程，尤其偏爱 `双阈值` 与 `滞后连接`。
- 必须会说明为什么“先平滑后求导”。原因不是形式上的固定顺序，而是求导会放大高频噪声，若不先平滑，边缘图会被噪声污染。
- 必须掌握 Canny 五步：高斯平滑、求梯度、非极大值抑制、双阈值、滞后连接。题目要求写步骤时，顺序不能错。

#### 关键概念
- `梯度 / 导数`：图像灰度函数在空间上的变化率。灰度变化快的位置往往对应边缘，因此一阶导数是边缘检测的核心工具。
- `离散差分核`：用有限差分近似连续导数。`[-1,1]` 是最简单的一维差分；Roberts、Prewitt、Sobel 都是其二维扩展。它们的差别主要体现在模板尺寸、方向与抗噪能力。
- `先平滑后求导`：真实图像含噪，导数会把噪声也放大。先做高斯平滑，再计算导数，可得到更稳定的边缘响应。
- `高斯导数 / DoG`：本章主线仍是高斯导数与 Canny；DoG 这里只作补充了解，可知道它和尺度空间有关，但考试重点不是靠 DoG 展开作答。
- `NMS`：非极大值抑制。沿梯度方向比较局部邻居，只保留幅值局部最大的点，把宽边变细边。
- `双阈值`：用高阈值和低阈值把像素分成强边缘、弱边缘、非边缘。这样做是为了同时降低漏检和误检。
- `滞后连接`：只保留与强边缘连通的弱边缘，丢掉孤立弱响应。它利用“真实边缘通常是连续的”这一假设。

#### 关键公式与符号意义
- 梯度向量：`\nabla I = [I_x, I_y]^T`。`I_x`、`I_y` 分别是 x、y 方向的一阶导数。核心含义：梯度指向灰度增长最快的方向，而边缘方向与梯度方向垂直。常见误区是把“梯度方向”和“边缘延伸方向”当成同一个方向。
- 梯度幅值与方向：`|\nabla I| = sqrt(I_x^2 + I_y^2)`，`θ = atan2(I_y, I_x)`。`|\nabla I|` 用来判断边缘强弱，`θ` 用于 NMS 判断该沿哪个方向比较。考试若问 NMS 为什么需要方向信息，就应回到这两个量。
- 高斯导数思想：`∂(G * I)/∂x = (∂G/∂x) * I`。这说明“先高斯平滑再求导”与“直接用高斯导数核卷积”是等价的。核心考法是解释为什么能把两步合成一步。
- Canny 双阈值分类：当 `|\nabla I| ≥ T_H` 时为强边缘；`T_L ≤ |\nabla I| < T_H` 时为弱边缘；`|\nabla I| < T_L` 时抑制。`T_H`、`T_L` 分别是高低阈值。常见误区是把弱边缘直接保留；正确做法是交给滞后连接再决定。

#### 高频比较与易错点
- `Roberts / Prewitt / Sobel`：Roberts 是 `2×2`、定位敏感但更怕噪声；Prewitt 是 `3×3`、结构简单；Sobel 也是 `3×3`，但中央权重更大，兼顾差分与平滑，抗噪性更好。选择题很爱考这一组。
- `先求导后平滑` 是错的默认直觉：顺序一错，噪声会先被放大，再难以补救。课程强调的是“先抑噪，再检测变化”。
- `NMS vs 双阈值`：NMS 的任务是“细化边缘”，双阈值的任务是“分级筛选边缘”，二者不互相替代。很多同学会把双阈值误写在 NMS 前面。
- `双阈值 vs 滞后连接`：双阈值只做分类，不决定最终保留哪些弱边缘；滞后连接才根据连通关系决定弱边缘是否留下。判断题喜欢把这两步混成一步。
- `DoG`：补充了解即可，它强调尺度差分思想；本章真正要稳拿分的主线仍是高斯导数、梯度/NMS 和 Canny 五步。

#### 可能出题方式
- `选择`：判断某差分模板检测的边缘方向；比较 Sobel 和 Roberts 的模板大小与抗噪能力；判断 Canny 步骤中哪一步不属于标准流程。
- `判断`：例如“梯度方向与边缘方向相同”应判错；“Canny 中 NMS 用于细化边缘”应判对；“双阈值后所有弱边缘都保留”应判错。
- `计算`：给 `I_x`、`I_y`，算梯度幅值和方向；给差分模板与小图像，求某点响应；若题目较基础，也可能只要求说明哪类算子更容易受噪声影响。
- `流程`：完整写 Canny 五步时建议固定模板：`高斯平滑 -> 计算梯度幅值与方向 -> NMS -> 双阈值 -> 滞后连接`，并在每步后补一句作用。
- `论述`：重点会落在“为什么先平滑后求导”“NMS 如何把边缘变细”“双阈值与滞后连接如何兼顾检出率与误检率”。回答时一定显式写出 `双阈值` 和 `滞后连接`。

### Ch05_1 拟合
#### 本章核心考点
- 本章去年分值低，但属于方法基础章，重点覆盖 `最小二乘`、`全最小二乘`、`鲁棒估计`、`RANSAC`。深度可以略低于 Ch03/Ch04，但术语不能混。
- 核心问题是：已知模型类型时，怎样从一堆带噪点里估计参数；如果存在离群点，普通最小二乘为什么会失效；RANSAC 为什么更稳。
- 题目若与 Ch05_2 联动，常把“拟合一条线”作为例子，借此区分参数估计法与投票法。

#### 关键概念
- `最小二乘`：选择参数，使残差平方和最小。在线拟合里，常见形式是让点到模型的误差尽可能小。它适合噪声较小、离群点较少的情况。
- `垂直最小二乘`：以 `y = mx + b` 为模型，最小化各点在 y 方向上的偏差平方和。优点是推导简单；缺点是不具旋转不变性，遇到近垂直直线会很不稳定。
- `全最小二乘`：最小化点到拟合直线的正交距离，而不是只看某一个坐标方向的误差。它比普通直线回归更符合几何意义，也更适合方向任意的直线。
- `鲁棒估计`：通过让大残差点的影响饱和或降低权重，减轻离群点对结果的破坏。思想上比普通最小二乘更抗异常值。
- `RANSAC`：随机抽最小样本集，生成候选模型，再统计支持该模型的内点数，重复多次选出最好模型。它适合内点中混有较多离群点的场景。

#### 关键公式与符号意义
- 普通最小二乘直线拟合：`E = Σ_i (y_i - m x_i - b)^2`。`(x_i, y_i)` 是样本点，`m` 是斜率，`b` 是截距。核心含义：让纵向残差平方和最小。常见考法是问“为什么叫平方和”，答“因为误差平方后可避免正负抵消并惩罚大误差”。
- 正规方程写法：`X^T X β = X^T Y`。`β` 是待估参数向量。考试通常不要求你完整矩阵推导，但要知道它是最小二乘闭式解的基础。
- 全最小二乘直线形式：`ax + by = d`，且常加约束 `a^2 + b^2 = 1`。这里 `(a,b)` 是单位法向量，`d` 是直线到原点的有符号距离。核心含义：用法向形式避免垂直线斜率无穷大的问题。
- 点到直线距离：`|a x_i + b y_i - d|`，在 `a^2+b^2=1` 时就是正交距离。全最小二乘最小化的是这些距离的平方和。常见误区是忘了单位法向量约束，导致距离表达式不成立。
- RANSAC 迭代次数常用关系：`N = log(1-p) / log(1-(1-e)^s)`。`p` 是期望成功概率，`e` 是离群点比例，`s` 是最小样本数。考试更常考符号意义和趋势：离群点越多、最小样本数越大，需要的迭代次数越多。

#### 高频比较与易错点
- `最小二乘 vs 全最小二乘`：前者通常最小化某一坐标方向残差，推导简单；后者最小化正交距离，几何意义更合理。易错点是把两者都说成“点到直线距离最小”。
- `最小二乘 vs 鲁棒估计`：最小二乘对大残差平方惩罚，因此极易被离群点带偏；鲁棒估计会压低大残差点权重，更稳但求解常需迭代。
- `鲁棒估计 vs RANSAC`：鲁棒估计通常是在全部样本上做加权优化；`RANSAC` 是随机采样加一致性筛选。若离群点比例很高，RANSAC 往往更合适。
- `RANSAC` 不是“永远最优”：它依赖阈值、迭代次数、最小样本数等参数，内点比例太低时会很慢甚至失败。论述题里要写出这一代价。
- `RANSAC 内点阈值`：阈值过小会把本应属于模型的点误判成外点，导致内点数不足、模型不稳定；阈值过大会把离群点也吞进去，导致估计结果被污染。

#### 可能出题方式
- `选择`：判断哪种方法对离群点更鲁棒；判断普通最小二乘是否适合垂直直线；判断 `RANSAC` 的基本步骤。
- `判断`：例如“RANSAC 直接使用全部点一次求闭式解”应判错；“全最小二乘最小化的是正交距离”应判对。
- `计算`：若考得浅，通常是写残差函数、说明参数含义，或根据离群点比例判断迭代次数变化趋势，不一定要求完整矩阵求解。
- `流程`：写 `RANSAC` 时建议固定为“随机采样最小子集 -> 拟合候选模型 -> 计算内点集合 -> 记录最佳模型 -> 用全部内点重估参数”。
- `论述`：可围绕“为什么最小二乘怕离群点”“为什么全最小二乘比竖直残差更自然”“RANSAC 何时优于普通拟合”作答，显式写出 `RANSAC` 的适用场景与代价。

### Ch05_2 霍夫变换
#### 本章核心考点
- 霍夫变换的核心不是“会背公式”而是理解映射关系：`图像空间中的点 -> 参数空间中的曲线`，多个共线点在参数空间中交于同一峰值。
- 直线检测必须会写 `ρ = x cosθ + y sinθ`，并说明 `ρ`、`θ` 的几何意义，以及为什么这种表示优于 `y = mx + b`。
- 还要会说明 `累加器投票`、`噪声影响`、`圆霍夫`、`广义霍夫`，并能与 `RANSAC` 做简要对比。

#### 关键概念
- `参数空间`：不是在原图上找线，而是把“模型参数”当成坐标轴去统计支持度。图像中的几何结构会在参数空间里形成峰值。
- `图像空间中的点 -> 参数空间中的曲线`：对一条未知直线上的单个点来说，可能通过它的直线不止一条，所以在参数空间里它不会对应单一点，而是一条候选曲线。
- `累加器投票`：把参数空间离散成网格，每个边缘点把自己支持的参数格子加一票。得票高的格子代表很多点共同支持该模型。
- `ρ-θ 表示`：用法向距离和法向角度描述直线，避免斜率无穷大的问题，因此可以统一表示竖直线。
- `圆霍夫`：将模型从直线扩展到圆，参数通常是圆心和半径。参数维数更高，所以计算量显著上升。
- `广义霍夫`：不仅可找直线和圆，也可找由模板定义的更复杂形状。核心思想仍然是“模板特征投票到参考点或参数配置”。

#### 关键公式与符号意义
- 直线极坐标表示：`ρ = x cosθ + y sinθ`。`ρ` 是原点到直线的有符号垂直距离，`θ` 是该垂线与 x 轴的夹角，也可理解为直线法向量方向。核心含义：一条直线由 `(ρ, θ)` 唯一确定。常见误区是把 `θ` 当成直线本身的倾角；更准确地说，它是法向角。
- 点到参数空间映射：对固定图像点 `(x_0, y_0)`，满足该点的所有直线参数组成曲线 `ρ(θ) = x_0 cosθ + y_0 sinθ`。因此一个点在参数空间中是一条正弦型曲线，而不是一个点。
- 累加器更新：对每个边缘点遍历离散 `θ`，计算对应 `ρ`，令 `H(θ, ρ) = H(θ, ρ) + 1`。`H` 是累加器数组。常见考法是问“峰值代表什么”，应答“代表很多边缘点对同一参数组合达成一致投票”。
- 圆霍夫常见参数式：`(x-a)^2 + (y-b)^2 = r^2`。`(a,b)` 是圆心，`r` 是半径。若 `r` 已知，则参数空间通常是二维 `(a,b)`；若 `r` 也未知，则是三维 `(a,b,r)`。这正是其计算代价高于直线霍夫的原因。

#### 高频比较与易错点
- `m-b 表示 vs ρ-θ 表示`：`y = mx + b` 对垂直线不友好，且参数域无界；`ρ-θ` 统一且稳定。若题目问为什么课程更推崇 `ρ-θ`，答这一点即可。
- `图像空间的直线` 与 `参数空间的曲线` 不要写反：一条图像中的直线对应参数空间中的一个点；一个图像中的点对应参数空间中的一条曲线。这个方向关系是本章最容易丢分的地方。
- `噪声影响`：噪声点会产生零散投票，真实结构会形成集中峰值；但噪声过多、参数网格过细或过粗，都会让峰值模糊或产生假峰。答题时要写“离散化粒度”这一层。
- `霍夫 vs RANSAC`：二者都能在噪声和离群点下找模型。霍夫更偏全局投票，可同时找多条线，但参数维数升高时代价大；`RANSAC` 更偏随机采样与验证，适合单模型或少量模型拟合。不要简单说谁绝对更好。
- `圆霍夫 vs 广义霍夫`：圆霍夫仍然是固定参数化形状；广义霍夫是把复杂模板特征也变成投票表，适用范围更广，但建模与计算更复杂。
- `离散化粒度标准答法`：参数空间离散过粗会把不同直线压到同一格里，定位变粗、峰值混叠；离散过细会让投票分散、峰值不明显，同时计算量和存储量上升。

#### 可能出题方式
- `选择`：判断图像空间中的点在霍夫空间里对应什么；判断 `ρ = x cosθ + y sinθ` 中 `θ` 的意义；判断圆霍夫的参数维度。
- `判断`：例如“图像中的一条直线对应参数空间中的一条曲线”应判错；“霍夫变换可以检测多条直线”应判对；“RANSAC 与霍夫都能处理一定程度的噪声”通常判对。
- `计算`：给定一个点 `(x,y)` 和若干 `θ`，要求计算对应 `ρ`；或者给出参数峰值 `(ρ, θ)`，让你写出对应直线方程。此时务必先解释 `ρ`、`θ` 的含义。
- `流程`：写标准直线霍夫时可答“边缘提取 -> 离散参数空间 -> 每个边缘点按 `ρ = x cosθ + y sinθ` 投票 -> 在累加器中找峰值 -> 将峰值反映回图像空间得到直线”。
- `论述`：可考“霍夫为什么对断裂边缘仍有一定鲁棒性”“噪声为什么会造成假峰”“霍夫与 RANSAC 的适用场景比较”。这类题要同时写投票思想和代价。

### Ch06 角点检测
#### 本章核心考点
- 本章抓一条主线即可：`窗口沿不同方向微移时，灰度变化是否都明显`。若只有一个方向变化大，是边缘；若两个主方向都变化大，才是角点。考试最常落在 `Harris 二阶矩阵`、`特征值判据`、`响应函数 R` 和 `不变性分析`。
- Harris 的标准判断必须会原句写出：`两个特征值都大 -> 角点；一个大一个小 -> 边缘；都小 -> 平坦区。` 这是选择、判断、简答三类题的共同核心。
- 也可以把判据压缩记成：`两大一角点、一大一小边缘、都小平坦区`。
- 必须能解释为什么 Harris 比 Moravec 更稳。课程强调的关键词是：`连续方向信息`、`高斯加权窗口`、`旋转稳定`，而 Moravec 只看少量离散位移方向，容易有方向偏置。
- 去年和预测题都表明 Ch06 常考“会不会尺度不变”。结论要记死：`Harris 对平移协变、对旋转不变、对光照仿射变化部分稳定，但不具有尺度不变性。`

#### 关键概念
- `角点`：局部窗口向任意小方向移动，外观都会明显变化，因此它比边缘点更适合做匹配、跟踪和拼接。考试里“良好特征”的潜台词通常就是“可重复、可区分、定位稳”。
- `自相关/SSD 思想`：定义窗口位移后的灰度差
  `E(u,v) = Σ w(x,y)[I(x+u,y+v)-I(x,y)]²`。
  它不是要求你硬算，而是告诉你“一个点是不是角点”，可以用窗口移动后的误差增长速度判断。
- `二阶矩矩阵 second moment matrix`
  `M = Σ w(x,y) [[I_x², I_xI_y], [I_xI_y, I_y²]]`。
  它把局部梯度在两个方向上的变化强度汇总起来，是 Harris 的核心对象。
- `特征值判据`：若 `λ1, λ2` 都小，局部基本没纹理；若 `λ1 >> λ2` 或 `λ2 >> λ1`，只有一个主变化方向，是边缘；若 `λ1, λ2` 都大，说明两个正交主方向都显著变化，是角点。这个判据比只看单方向差分更完整。
- `Moravec`：早期角点检测器，思路是比较窗口在若干离散方向平移后的 SSD 变化。优点是直观，缺点是方向离散、对噪声和旋转不够稳。
- `可直接抄写的考试句式`：`Harris 的本质是利用局部梯度构成二阶矩阵，若窗口在两个主方向上都出现显著灰度变化，则该点应判为角点。`

#### 关键公式与符号意义
- 窗口位移误差：
  `E(u,v) = Σ w(x,y)[I(x+u,y+v)-I(x,y)]²`。
  其中 `w(x,y)` 是窗口权重，常取高斯；`(u,v)` 是微小位移。意义是“比较同一窗口平移前后有多不一样”。
- 小位移泰勒近似后：
  `E(u,v) ≈ [u v] M [u v]^T`。
  这一步的考试意义不是推导细节，而是说明角点判定被转成了一个二次型问题。
- 二阶矩阵：
  `M = Σ w(x,y) [[I_x², I_xI_y], [I_xI_y, I_y²]]`。
  `I_x, I_y` 分别是 x/y 方向导数；对角项表示单方向能量，非对角项表示方向相关性。
- Harris 响应函数：
  `R = det(M) - k(trace(M))² = λ1λ2 - k(λ1+λ2)²`，其中 `k` 常取 `0.04~0.06`。
  `det(M)` 反映两个方向同时大的倾向，`trace(M)` 反映总能量。`R` 大且为正通常对应角点，`R` 很小对应平坦区，`R` 为负往往对应边缘。
- 判定链条建议直接写：
  `先求 I_x、I_y -> 组成 M -> 计算 R 或看 λ1, λ2 -> 阈值化 -> 非极大值抑制得到角点。`
- 不变性作答链：
  `平移时导数和窗口整体平移，响应位置随之平移；旋转时 M 的特征向量会转，但特征值不变，所以 R 对旋转稳定；尺度变化会改变窗口与结构的相对大小，因此 Harris 不具尺度不变性。`

#### 高频比较与易错点
- `Harris vs Moravec`：Moravec 用少数离散方向的窗口移动比较，容易漏掉真实主方向；Harris 用导数构造连续方向的二阶矩阵，更平滑、更稳定、各向同性更好。考试若问“主要改进”，优先答这三点。
- `角点 vs 边缘`：边缘只有一个主方向变化大，所以窗口沿边缘方向移动变化小；角点在两个主方向都变化大，所以几乎往哪动都变。不要把“梯度大”直接等同于“角点”。
- `R 大` 不等于 `一定是角点` 的全部表述：规范答法是“`R` 较大且经过阈值和局部极大值筛选后保留为角点”。否则会把单纯高响应噪声点也算进去。
- `旋转不变` 不等于 `尺度不变`：这是 Ch06 最高频误区。Harris 对旋转稳定，但图像放大缩小时，同一点可能从角点变成边缘或反过来。
- `光照变化` 易错点：亮度平移 `I -> I+b` 对导数无影响，因此较稳；亮度缩放 `I -> aI` 会整体改变导数幅值，但在阈值适配时仍有一定稳定性。不要把它说成“完全光照不变”。
- `速判句`：`看 λ 比看图快：双大是角点，单大是边缘，双小是平坦。`

#### 可能出题方式
- `选择`：判断 Harris 是否尺度不变；判断 `λ1 >> λ2` 属于边缘还是角点；比较 Harris 与 Moravec 谁更各向同性。
- `判断`：例如“两个特征值都大说明是角点”判对；“Harris 对尺度变化不敏感”判错；“Moravec 比 Harris 更适合旋转场景”判错。
- `计算`：给出 `M = [[a,b],[b,c]]` 或直接给出 `λ1, λ2`，要求判断区域类型；也可能给出 `R = det(M)-k(trace(M))²` 要求写各符号意义，不一定真算数值。
- `流程`：标准流程可写为 `计算梯度 -> 在高斯窗口内累积二阶矩阵 -> 计算 Harris 响应 -> 阈值化 -> 非极大值抑制`。
- `论述`：最常见模板是“解释 Harris 判据并与 Moravec 对比”。可直接抄写：
  `Moravec 只在有限离散方向比较窗口变化，因此存在方向偏置；Harris 将局部梯度汇总成二阶矩阵，通过特征值同时衡量两个主方向上的变化，所以对旋转更稳定、对噪声更鲁棒，但仍不具尺度不变性。`

### Ch07 Blob / SIFT
#### 本章核心考点
- Ch07 的主线是 `从角点推广到带尺度的局部特征`。必须把 `尺度空间`、`LoG/DoG`、`特征尺度` 和 `SIFT 的四步` 串成一条链，不要把 blob 检测和描述子阶段割裂开。
- 考试高频句：`DoG 是尺度归一化 LoG 的高效近似；SIFT 先在尺度空间找极值点，再做方向分配和描述子构造。`
- 本章最容易直接出论述题的是 `SIFT 的不变性来源`。必须显式写：`SIFT 具有尺度不变性、旋转不变性，并对部分光照变化稳定。` 这三项分别来自尺度空间极值、主方向对齐、描述子归一化。
- 另一类高频题是“为什么 Harris 不够、为什么要 blob/scale selection”。标准回答是：`Harris 没有尺度选择机制，图像缩放后同一结构未必还能在同一窗口尺度下被稳定检测到。`

#### 关键概念
- `Blob`：图像中在某一尺度上显得像“亮/暗团块”的区域。它和边缘不同，blob 更关注区域中心及其特征尺度，而不是单条边界。
- `尺度空间`：把图像用不同 `σ` 的高斯核连续平滑，得到 `L(x,y,σ)`。直觉上是“同一图像从细看到粗”，便于找出某个结构最合适的观察尺度。
- `LoG`：高斯拉普拉斯 `∇²G`，常用于 blob 检测；乘上 `σ²` 后形成尺度归一化 LoG，才能公平比较不同尺度的响应强弱。
- `DoG`：相邻两个尺度的高斯图像相减
  `D(x,y,σ)=L(x,y,kσ)-L(x,y,σ)`。
  它不是另一个完全不同的算子，而是 LoG 的快速近似，因此是 SIFT 的检测基础。
- `特征尺度 characteristic scale`：同一结构在尺度空间中响应最大的那一层尺度。考试里若问“为什么能做到尺度不变”，核心就在这里。
- `SIFT`：Scale-Invariant Feature Transform。流程可记为 `尺度空间极值 -> 精定位去伪点 -> 方向分配 -> 描述子构造`。
- `可直接抄写的考试句式`：`SIFT 的思想是先做协变检测，再做不变描述：检测阶段找到与图像缩放同步变化的关键点尺度，描述阶段通过主方向对齐和归一化获得稳定特征。`

#### 关键公式与符号意义
- 高斯尺度空间：
  `L(x,y,σ) = G(x,y,σ) * I(x,y)`。
  `σ` 越大，平滑越强，看到的结构越粗。
- 尺度归一化 LoG：
  `σ²∇²G`。
  `σ²` 的作用必须会解释：不加归一化时，大尺度响应天然变小，无法直接比较；归一化后，真正匹配结构尺度的层才会显著峰值。
- DoG 近似：
  `G(x,y,kσ)-G(x,y,σ) ≈ (k-1)σ²∇²G`。
  这句是选择题和判断题高频点，结论就是 `DoG 近似 LoG，但计算更快`。
- 二值圆 blob 的典型结论：
  当 blob 半径为 `r` 时，最大 LoG 响应大致出现在 `σ ≈ r/√2`。
  考试不一定要求推导，但会借它问“什么叫特征尺度”。
- SIFT 极值检测：在 DoG 金字塔中，对每个候选点与当前层及上下相邻层的 `3×3×3` 邻域比较，若为局部极大/极小则保留为候选关键点。要点是“空间 + 尺度同时找极值”。
- 方向分配：在关键点邻域内统计梯度方向直方图，取主峰作为关键点主方向。若存在接近主峰的次峰，也可复制关键点并赋次方向。它直接支撑旋转不变性。
- 描述子：经典 SIFT 把邻域分成 `4×4` 小块，每块统计 `8` 个方向的梯度直方图，总维度 `4×4×8=128`。`128 维`是很常见的选择题记忆点。

#### 高频比较与易错点
- `LoG vs DoG`：LoG 更接近理论上的尺度归一化二阶导检测，DoG 是高效近似。考试问“谁更快”答 DoG，问“谁是 SIFT 实际采用的检测器”也答 DoG。
- `blob 检测 vs SIFT 描述`：blob/DoG 负责“在哪里、在什么尺度”；描述子负责“怎么表示这个点”。很多人会把 DoG 当成完整 SIFT，这会丢分。
- `Harris vs SIFT`：Harris 主要是平移/旋转稳定但无尺度机制；SIFT 通过尺度空间和主方向分配，同时获得尺度和旋转稳定。若题目问“为什么 SIFT 更适合匹配”，优先答这一点。
- `尺度不变` 与 `尺度协变` 要分开：检测到的关键点位置和特征尺度会随图像缩放而变化，这是协变；描述子在归一化后保持可比，这是不变。不会区分这两个词时，写“检测协变、描述不变”最稳。
- `SIFT 不变性来源` 必须显式背熟：`尺度不变性来自尺度空间极值检测；旋转不变性来自方向分配；对部分光照变化稳定来自梯度描述和归一化。`
- `易错句`：SIFT 不是完全光照不变，也不是完全仿射不变。更稳妥的表述是“对部分光照变化和一定视角变化具有鲁棒性”。

#### 可能出题方式
- `选择`：判断 DoG 与 LoG 的关系；判断 SIFT 哪一步保证旋转不变；判断 Harris 为什么不具尺度不变性。
- `判断`：例如“DoG 是 LoG 的快速近似”判对；“SIFT 的尺度不变性来自方向分配”判错；“SIFT 对部分光照变化具有稳定性”判对。
- `计算`：给出 `4×4` cell、每 cell `8` bins，要求求描述子维度 `128`；或给出 `σ` 与 blob 半径关系，要求判断哪一层更接近特征尺度。
- `流程`：可按 `构建高斯/DoG 金字塔 -> 检测尺度空间极值 -> 精定位并剔除低对比度/边缘响应点 -> 方向分配 -> 构造 128 维描述子` 作答。
- `论述`：可直接抄写：
  `SIFT 先用 DoG 在尺度空间中寻找局部极值，因此同一结构在不同缩放图像中会自动选到对应尺度；随后在关键点邻域统计主方向并对齐描述子，因此具有旋转不变性；最后用局部梯度直方图并做归一化，所以对部分光照变化也较稳定。`

### Ch08 纹理
#### 本章核心考点
- Ch08 不只是“记几个纹理算子名字”，而是要会把纹理表示分成三类：`统计纹理`、`滤波器组/纹理元 texton`、`局部编码如 LBP/GLCM`。考试喜欢从“怎么表示”和“为什么能区分材质”两个角度来考。
- 课件和预测都指向两个高频对象：`滤波器组` 与 `LBP`。此外必须补上 `GLCM` 的用途，因为判断题很容易考“共生矩阵统计的是什么”。
- 本章还要和 Ch10 接起来：`Bag-of-Features` 在图像识别里常被说成“来自纹理识别思想”，因为它本质上也是“局部模式量化 + 频率直方图”。
- 复习时优先记结论：`纹理通常不能靠单个边缘表达，而要靠局部模式在一个窗口内的统计分布来表达。`

#### 关键概念
- `纹理`：表面或区域中重复出现的局部模式，可能规则，也可能随机。它更像“整体统计外观”，不是单个边界或单个角点。
- `统计纹理`：不追踪每个像素的精确位置，而统计一个窗口内的灰度、梯度或编码分布，如均值、方差、直方图、共现关系。适合描述“粗糙、细密、规则、随机”等整体属性。
- `滤波器组 filter bank`：用多尺度、多方向、多类型滤波器去响应局部纹理，再把响应向量作为纹理特征。它抓的是“什么模式被哪些滤波器激活”。
- `texton`：把滤波器组响应向量聚类后的“纹理元/原型模式”。考试里可以把它理解成“纹理世界里的视觉词”。
- `LBP`：Local Binary Pattern，围绕中心像素比较邻域像素大小，形成局部二进制编码。优点是简单、快、对单调灰度变化稳。
- `GLCM`：Gray-Level Co-occurrence Matrix，统计特定方向和距离上灰度值成对出现的频率，再据此提取对比度、同质性、能量、熵等统计特征。
- `LBP 与 GLCM 用途区别` 必须明写：`LBP 更偏局部微结构编码，适合快速做纹理分类、表面描述和人脸局部纹理分析；GLCM 更偏灰度对的空间共现统计，适合分析粗糙度、方向性、规则性等整体统计特性。`
- `可直接抄写的考试句式`：`纹理分析的关键不是保存每个像素位置，而是在局部窗口中总结重复模式的统计规律。`

#### 关键公式与符号意义
- LBP 基本编码：
  `LBP = Σ s(g_p-g_c)2^p`，其中
  `s(x)=1 (x≥0), 0 (x<0)`。
  `g_c` 是中心像素灰度，`g_p` 是第 `p` 个邻域像素。意义是“把邻域相对中心是亮还是暗编码成二进制模式”。
- 旋转不变 LBP：对二进制模式做循环移位，取最小编码作为代表。它的作答重点不是公式，而是“旋转后模式顺序变了，但本质局部结构没变，因此用循环等价类合并”。
- GLCM 定义：`P(i,j; d,θ)` 表示相距 `d`、方向为 `θ` 的两个像素，其灰度分别为 `i` 与 `j` 的出现频率。考点是 `i,j` 是灰度对，不是坐标。
- 常见 GLCM 特征：
  `Contrast = Σ(i-j)²P(i,j)`，
  `Energy = ΣP(i,j)²`，
  `Homogeneity = Σ P(i,j)/(1+|i-j|)`。
  不一定要求全背，但至少知道它们都来自共生矩阵统计。
- 滤波器组纹理流程：
  `多滤波器卷积 -> 得到每像素响应向量 -> 聚类得到 texton -> 在局部窗口统计 texton 直方图 -> 分类或分割。`
- Bag-of-Features 的纹理来源作答链：
  `纹理识别先做局部模式聚类并统计频率 -> 这一思想推广到一般图像局部特征 -> 形成视觉词汇和词频直方图。`

#### 高频比较与易错点
- `LBP vs GLCM`：LBP 直接编码局部邻域相对大小关系，突出微结构类型；GLCM 统计灰度对共现，突出全局统计和方向关系。若题目问“哪个更适合做灰度共现方向性分析”，答 GLCM；问“哪个更适合轻量局部纹理编码”，答 LBP。
- `滤波器组 vs 统计灰度`：单纯均值方差信息量有限；滤波器组能把不同方向、尺度的局部结构分开。考试若问“为什么不用边缘图直接做纹理”，就答边缘太零碎，难表达重复模式分布。
- `texton vs 视觉词`：在纹理课语境中常说 texton，在识别课语境中常说 visual word；思想相近，都是“聚类后的局部模式原型”。
- `BoF 来源` 易错点：BoF 不是凭空出现的分类技巧，它继承了纹理识别里“无序局部模式统计”的思路。这个跨章节联系很适合论述题加分。
- `易错句`：纹理分析通常对精确几何位置不敏感，但不代表“完全不看空间关系”。例如 GLCM 明确就编码了距离和方向，空间金字塔也会部分补回空间信息。
- `速判句`：`LBP 看局部明暗模式，GLCM 看灰度成对出现，filter bank 看多方向多尺度响应。`

#### 可能出题方式
- `选择`：判断哪类方法属于统计纹理；判断 GLCM 统计的是灰度对共现；判断 LBP 是否依赖邻域相对大小而不是绝对灰度。
- `判断`：例如“LBP 对单调光照变化较稳定”判对；“GLCM 只记录单个像素灰度直方图”判错；“Bag-of-Features 的思想与纹理元统计有关”判对。
- `计算`：给一个 `3×3` 邻域，要求写出基本 LBP 编码；或给出某个方向距离下的灰度对，要求说明如何填 GLCM 某个单元。
- `流程`：滤波器组题可写 `卷积 -> 响应向量 -> 聚类成 texton -> 局部直方图 -> 分类/分割`；LBP 题可写 `邻域比较 -> 二进制编码 -> 直方图 -> 分类`。
- `论述`：可直接抄写：
  `纹理通常由重复局部模式组成，单个边缘难以稳定表达，因此更适合用统计方式描述。LBP 通过局部二值编码捕捉微结构，GLCM 通过灰度共现统计描述方向性和粗糙度，滤波器组与 texton 则进一步把多尺度多方向响应组织成可分类的纹理表示。`

### Ch09 分割
#### 本章核心考点
- Ch09 的关键词必须成组记忆：`k-means`、`mean shift`、`graph cuts`、`normalized cut`、`形态学识图`。其中真正最容易出大题的是形态学识图和图分割思想。
- 这章的总思路是：`把像素或区域按相似性分组`。相似性可以来自颜色/灰度、位置、纹理，也可以来自图上的亲和度。
- 形态学题虽然不一定在本章课件主线里占最大篇幅，但从真题和预测看，它是最值得背判断口诀的部分。一定要准备“看到图就能先判操作”的速判句。
- 另一高频点是 `最小割为什么不好、normalized cut 为什么要归一化`。考试标准表述是：`最小割偏向切掉很小的孤立块，normalized cut 通过考虑区域总体连接度来避免这种偏置。`

#### 关键概念
- `分割`：把图像划成若干内部相似、彼此不同的区域。它介于底层像素处理和高层识别之间，常用于超像素、预处理或目标候选生成。
- `k-means 分割`：把像素特征如 `(r,g,b,x,y)` 聚成 `k` 类。优点是简单；缺点是要预先给定 `k`、对初始化敏感、倾向球形簇、对离群点敏感。
- `mean shift`：在特征空间中不断向局部密度峰值移动窗口中心，最后把收敛到同一众数的样本归为一类。它是非参数方法，不必预设簇形状，但带宽选择很关键。
- `graph cuts`：把图像看成加权图，像素/区域是节点，相似性是边权；分割变成“切掉哪些边”。核心直觉是“同一区域内边权大，不同区域之间边权小”。
- `normalized cut`：在最小化割边权重的同时，对两边的总体连接度做归一化，避免只切掉一个很小的孤立区域。
- `形态学`：基于结构元素对二值或灰度图做集合运算。识图题常考 `腐蚀`、`膨胀`、`开运算`、`闭运算`、`边界提取` 的视觉效果和用途。
- `可直接抄写的考试句式`：`分割的本质是定义相似性并做分组；不同方法的差别主要在于相似性的表达方式以及如何优化分组结果。`

#### 关键公式与符号意义
- k-means 目标函数：
  `J = Σ_{i=1}^k Σ_{x∈C_i} ||x-μ_i||²`。
  `C_i` 是第 `i` 类，`μ_i` 是类中心。意义是让每类内部尽量紧凑。
- mean shift 更新直觉：在当前窗口内求加权均值，再把窗口中心移到该均值位置，重复直到收敛到局部密度峰。考试更常问“它找什么”而不是详细公式，答案是“找众数/局部极大密度点”。
- 图割中的割代价：
  `cut(A,B) = Σ_{i∈A,j∈B} w(i,j)`。
  它只看两部分之间被切断的边权总和，因此容易偏爱切掉小块。
- normalized cut：
  `Ncut(A,B)=cut(A,B)/assoc(A,V)+cut(A,B)/assoc(B,V)`。
  `assoc(A,V)` 表示集合 `A` 与整个图的总连接权重。归一化的意义是“切口小”之外，还要“切开的每一边本身是个完整整体”。
- normalized cut 的特征值形式：
  `(D-W)y = λDy`。
  只要知道 `W` 是邻接/亲和矩阵，`D` 是度矩阵即可；题目通常不要求推导，但会考它属于谱分割思路。
- 形态学定义：
  `A∘B = (A⊖B)⊕B` 为开运算，
  `A•B = (A⊕B)⊖B` 为闭运算。
  这是识图题必须会写的标准表达。
- 形态学速判口诀必须显式写出：
  `缩小看腐蚀，扩大看膨胀；去小噪点、断细连接多半是开运算；填小孔洞、连小裂缝多半是闭运算；实心变轮廓通常是边界提取。`

#### 高频比较与易错点
- `k-means vs mean shift`：k-means 需要预设 `k`，找的是若干中心；mean shift 不必先给类别数，找的是密度峰。k-means 快但假设更强，mean shift 更灵活但计算更重。
- `graph cut vs normalized cut`：最小割只关心切口总代价，容易把一个很小的孤立区域切出去；normalized cut 额外考虑两边的内部连接总量，因此更平衡。若题目问“为什么要 normalized”，就答“避免偏向小碎片”。
- `颜色聚类分割 vs 图分割`：前者更像在特征空间做聚类，不一定空间连通；后者显式利用像素间连接关系，更容易表达邻接一致性。
- `开运算 vs 闭运算`：开是先腐后胀，主要去掉小前景噪点、断开细连接；闭是先胀后腐，主要填小孔、接小缝。把顺序写反是最常见失分点。
- `腐蚀 vs 膨胀`：腐蚀让前景收缩，膨胀让前景扩张。识图时先看“总体轮廓是瘦了还是胖了”，比死背定义更快。
- `速判句`：`看图先看面积变化，再看孔洞和细连接。缩了先想腐蚀，胖了先想膨胀；主体基本不变但小噪点没了是开，主体基本不变但小洞没了是闭。`

#### 可能出题方式
- `选择`：判断 mean shift 是否非参数；判断 normalized cut 相比 min-cut 解决了什么问题；判断开闭运算的先后顺序。
- `判断`：例如“k-means 需要指定 k”判对；“mean shift 一定先给类别数”判错；“normalized cut 只看割边权重”判错。
- `计算`：给出几个像素/特征点，要求说明 k-means 如何迭代分配；或给出简单二值结构，让你判断做一次腐蚀/膨胀后会怎样变化。
- `流程`：图分割流程可写 `构图 -> 定义边权/亲和度 -> 求 cut 或 Ncut -> 按结果二分或递归分割`；mean shift 流程可写 `初始化窗口 -> 计算局部均值 -> 移动窗口 -> 收敛后合并同峰值样本`。
- `论述`：形态学识图题可以直接抄：
  `先判断前景是整体收缩还是扩张，再判断小噪点、细连接、小孔洞是否发生变化。若图像去掉了孤立小白点且主体轮廓大体保持，则通常是开运算；若填平了小黑洞或连接了细小裂缝，则通常是闭运算。`

### Ch10 识别
#### 本章核心考点
- Ch10 先记“识别三问题”：`表示什么`、`怎么学`、`怎么在新图像上判别`。课件明确把它们称为 `表示 / 学习 / 识别` 三个基本问题，考试非常适合直接出简答。
- 本章至少要会分清 `分类、检测、分割` 三类任务，但更关键的是 `生成式 vs 判别式`。这是判断题和论述题的高频交叉点，必须写清到底学的是 `p(x|y)` 还是 `p(y|x)` / 决策边界。
- 传统识别主线要能说出 `Bag-of-Features -> 视觉词汇 -> 词频直方图 -> 分类器`，并补一句 `空间金字塔是在词袋基础上加入粗空间布局信息`。
- 还要明确 `过拟合`：训练集高准确率不代表泛化好，模型过复杂、词汇过大、训练样本不足都可能引发过拟合。

#### 关键概念
- `识别任务`：分类回答“这是什么类”，检测回答“是什么类且在哪里”，分割回答“每个像素属于什么”。在识别章节里，默认主线更偏分类与类别识别。
- `表示问题`：如何把图像变成可学习的特征，如原始像素、局部描述子、视觉词直方图、空间金字塔等。
- `学习问题`：给定训练数据，如何估计模型参数或分类器，例如最近邻、SVM、Boosting、朴素贝叶斯等。
- `识别问题`：训练完后，如何对新图像打分、分类、排序或搜索。课件里会和滑动窗口、NMS 等实际搜索策略相连。
- `生成式模型`：学习类别如何生成数据，典型是建模 `p(x|y)` 和先验 `p(y)`，再用贝叶斯公式求后验。优点是可解释、能显式描述数据分布；缺点是建模假设强。
- `判别式模型`：直接学习 `p(y|x)` 或决策边界，如 SVM、逻辑回归、神经网络。优点是分类目标直接，往往性能更强；缺点是对数据分布解释较弱。
- `Bag-of-Features (BoF)`：把局部特征量化成视觉词，统计整幅图中各视觉词的频率，忽略大部分精确顺序。
- `视觉词汇 visual vocabulary`：用聚类（常见是 k-means）从大量局部描述子中学到的码本；每个聚类中心就是一个视觉词。
- `空间金字塔`：把图像按 `1×1、2×2、4×4...` 分块，每块分别做 BoF 直方图并拼接，部分补回 BoF 丢掉的空间布局信息。
- `可直接抄写的考试句式`：`识别系统通常先设计稳定表示，再在训练集上学习分类器，最后在新图像上根据得分或后验完成判别。`

#### 关键公式与符号意义
- 贝叶斯公式作答框架：
  `p(y|x) ∝ p(x|y)p(y)`。
  这里 `x` 是图像特征，`y` 是类别。它正好对应生成式与判别式的分野。
- `生成式 vs 判别式` 必须明写：
  `生成式重点学习 p(x|y) 和 p(y)`，再推断 `p(y|x)`；
  `判别式重点直接学习 p(y|x)` 或直接学习分类边界。
  这是本章最关键的判定句。
- k-means 在视觉词汇中的作用：
  `J = Σ_i ||x_i - μ_{c(i)}||²`。
  这里不是最终分类器，而是“建词典”的无监督步骤。要防止把“聚类建码本”和“监督分类”混成一步。
- BoF 流程公式化写法：
  `局部特征 -> 最近视觉词索引 -> 词频直方图 h -> 用 h 输入分类器`。
  核心意义是把可变数量局部特征压缩成固定维度全局向量。
- 空间金字塔可直接写成：
  `在 level 0/1/2 ... 的多个网格上分别统计局部词频，再把各层直方图串联。`
  考点不在复杂公式，而在“加入粗空间信息”。
- 过拟合作答链：
  `训练误差很低但测试误差升高 -> 模型记住了训练样本细节而不是一般规律 -> 需靠更多数据、正则化、降模型复杂度或减小词汇规模缓解。`

#### 高频比较与易错点
- `生成式 vs 判别式`：生成式回答“这类数据长什么样”；判别式回答“类别边界在哪里”。标准考试句式可写：
  `生成式先建模数据分布，再做分类；判别式直接面向分类结果优化。`
- `BoF vs 空间金字塔`：BoF 基本不看精确空间布局，适合纹理式无序统计；空间金字塔在不同网格块分别统计词频，因此比普通 BoF 多保留了一部分位置关系。
- `视觉词汇学习 vs 最终识别`：k-means 聚类是无监督建码本；SVM/最近邻/贝叶斯等才是后续识别器。把这两步混为一谈是高频错误。
- `分类 vs 检测 vs 分割`：分类只给类别，检测给类别和框，分割给像素标签。Ch10 常和 Ch11 混考，答题时一定把输出层级写清。
- `过拟合`：不是“训练准确率低”，而是“训练好、测试差”。若题目说“模型太复杂、词汇过大、样本太少”，应首先联想到过拟合。
- `速判句`：`p(x|y) 更像生成式，p(y|x) 更像判别式；BoF 看词频，空间金字塔看分块词频。`

#### 可能出题方式
- `选择`：判断某模型属于生成式还是判别式；判断 BoF 中视觉词汇由什么学习得到；判断空间金字塔相对普通词袋增加了什么信息。
- `判断`：例如“训练准确率高说明泛化一定强”判错；“SVM 更接近判别式模型”判对；“k-means 是 BoF 中常见的码本学习方法”判对。
- `计算`：给若干局部特征与聚类中心，要求做最近邻量化并写出简单词频直方图；或给空间金字塔层数，说明最终表示由哪些层拼接组成。
- `流程`：标准 BoF 流程可写 `采样/检测局部区域 -> 提取描述子 -> k-means 学视觉词汇 -> 特征量化 -> 统计词频直方图 -> 训练分类器`。
- `论述`：可直接抄写：
  `生成式模型通过学习各类别的数据分布 p(x|y) 及先验 p(y) 来进行分类，强调“这类样本如何生成”；判别式模型则直接学习 p(y|x) 或决策边界，强调“怎样把类别分开”。在传统图像识别中，Bag-of-Features 先把局部描述子量化为视觉词，再统计词频；空间金字塔进一步按多尺度网格分别统计词频，从而补充了粗空间布局信息。`

### Ch11 目标检测
#### 本章核心考点
- Ch11 要抓住经典滑动窗口检测框架：`多尺度窗口搜索 -> 对每个窗口提特征并分类 -> 用 NMS 去重`。即使题目只问某个算法，也建议先把这条主线写出来。
- `Viola-Jones` 必须明确写三要素：`积分图`、`AdaBoost/boosting`、`级联分类器`。这是课程和预测题都点名的核心。
- `HOG` 的核心思想也必须单独背一句：`用局部区域内的梯度方向直方图来描述目标轮廓和形状，再配合滑动窗口分类器进行检测。`
- 这章容易和 Ch10 混：识别只要判类别，检测还要给位置。答题时把“窗口搜索”和“NMS”写出来，区分度就够了。

#### 关键概念
- `滑动窗口`：在图像不同位置、不同尺度上滑动固定大小窗口，对每个窗口判定“目标/非目标”。优点是简单通用，缺点是候选窗口数量巨大，计算代价高。
- `NMS`：Non-Maximum Suppression，保留高分框并去掉与其重叠过大的低分框。它不是分类器，而是检测后处理。
- `boosting`：把多个弱分类器加权组合成强分类器，并让后续学习更关注前面分错的样本。在 Viola-Jones 里，它还承担“从海量 Haar 特征中选少量有用特征”的任务。
- `Viola-Jones`：经典实时人脸检测框架。三个核心部件是 `Haar-like 矩形特征 + 积分图快速计算 + AdaBoost 特征选择/分类 + 级联分类器快速拒绝负样本`。若只许写三要素，就写 `积分图、boosting、级联分类器`。
- `积分图 integral image`：每个位置存储其左上矩形区域像素和，因此任意矩形区域求和只需常数次加减。它解决的是“矩形特征算得太慢”的问题。
- `级联分类器`：把若干阶段串联，前几级用极少特征快速过滤绝大多数背景，后几级再精细判断，换来实时速度。
- `HOG`：Histogram of Oriented Gradients。先算梯度，再在 cell 内统计方向直方图，最后做 block 归一化。它强调目标轮廓、边缘分布和局部形状信息。
- `行人检测`：Dalal-Triggs 框架通常写成 `滑动窗口 + HOG + 线性 SVM + NMS`，是课程中的经典范式。
- `可直接抄写的考试句式`：`目标检测要同时解决“是什么”和“在哪里”，因此除了分类器本身，还必须设计高效搜索和重叠框抑制机制。`

#### 关键公式与符号意义
- 积分图定义：
  `II(x,y)=Σ_{x'≤x,y'≤y} I(x',y')`。
  其中 `II(x,y)` 是左上累计和。任意矩形求和可由四个角做加减得到，这就是它快的原因。
- 矩形区域求和：
  `sum = A - B - C + D`（视角点命名而定，也可写成 `D + A - B - C`）。
  关键不是字母顺序，而是“用四角值常数时间求任意矩形和”。
- Boosting 最终分类器形式：
  `H(x)=sign(Σ_t α_t h_t(x))`。
  `h_t(x)` 是弱分类器，`α_t` 是其权重。考试只要会解释“多个弱分类器加权组成强分类器”即可。
- Viola-Jones 作答链：
  `滑动窗口产生候选 -> Haar-like 特征描述窗口 -> 积分图快速算特征 -> AdaBoost 选特征并训练强分类器 -> 级联结构快速拒绝背景窗口 -> 输出检测框。`
- HOG 核心流程：
  `求梯度 -> 在 cell 内统计方向投票 -> 以 block 做局部归一化 -> 拼接成窗口描述子 -> 分类器打分。`
  其中“方向直方图 + 局部归一化”是最关键的两个点。
- 行人检测标准链：
  `多尺度窗口 -> HOG 特征 -> 线性 SVM 评分 -> NMS 合并重叠框。`
  这是考试里最稳的四步答案。

#### 高频比较与易错点
- `滑动窗口 vs 分类`：滑动窗口不是特征，也不是分类器，而是搜索策略。它解决“去哪里看”，分类器解决“看见的像不像目标”。
- `积分图 vs HOG`：积分图服务于 Haar 矩形特征的快速求和；HOG 统计梯度方向直方图，不依赖积分图。把两者混成一个框架是常见错误。
- `Viola-Jones vs HOG 行人检测`：前者偏 Haar-like 矩形特征 + boosting + 级联，擅长刚性较强的人脸；后者偏梯度方向统计 + 线性 SVM，更擅长行人轮廓模板。若比较，重点答“特征类型”和“分类框架”不同。
- `boosting vs 级联`：boosting 是训练强分类器/选特征的方法；级联是把多个阶段串起来加速检测的结构。二者相关但不是同一个概念。
- `NMS`：不是提高分类精度的训练技巧，而是测试阶段合并重复框的后处理。答检测流程时若漏掉 NMS，通常会显得不完整。
- `HOG 核心思想` 必须显式写：`HOG 用局部梯度方向分布而不是原始像素值表示目标，因此更关注轮廓和形状，对一定光照变化更稳。`
- `速判句`：`积分图管加速，boosting管选特征和分类，级联管早拒绝；HOG管形状，SVM管判别，NMS管去重。`

#### 可能出题方式
- `选择`：判断 Viola-Jones 三要素；判断积分图解决了什么问题；判断 HOG 更偏描述什么信息。
- `判断`：例如“滑动窗口检测需要在多位置多尺度上评估窗口”判对；“NMS 属于训练阶段特征学习”判错；“HOG 主要统计局部梯度方向分布”判对。
- `计算`：给积分图四角值，要求求矩形区域和；或给多个检测框得分与重叠关系，要求说明 NMS 会保留哪一个。
- `流程`：Viola-Jones 可写 `滑动窗口 -> Haar 特征 -> 积分图快速求值 -> AdaBoost -> 级联分类器 -> 输出人脸框`；HOG 行人检测可写 `多尺度窗口 -> HOG -> 线性 SVM -> NMS`。
- `论述`：可直接抄写：
  `Viola-Jones 之所以能实时做人脸检测，关键在于三点：积分图把矩形特征计算降到常数时间，AdaBoost 从海量 Haar-like 特征中选出少量有效特征并组成强分类器，级联分类器让大多数背景窗口在前几级就被快速拒绝。HOG 行人检测则改用局部梯度方向直方图描述人体轮廓，再结合滑动窗口和线性 SVM 完成检测，最后用 NMS 去掉重复框。`
